# Building envelope

The existing building envelope needs to be retrofitted with extra insulation and newer glazings in transformation projects.

**Internal insulation** is basically no-go due to moisture concerns. In basements, however, internal plates of calcium silicate -- if mounted correctly -- works well, but has limited insulation value.

On top of **existing basement floors** -- if there is room height -- you can use PIR insulation in combination with a tight vapour barrier and new flooring.

## U-value of retrofitted wall

One advantage of retrofitting a building with external insulation is that you remove the existing thermal bridges.

However, thermal bridges are relatively more significant in modern well-insulated buildings and cannot be ignored.

Consequently, Building Code DK recommends to add 50% to the U-values due to linear losses. (<https://www.bygningsreglementet.dk/tekniske-bestemmelser/11/brv/energiforbrug-2/>)
